# Data
* `product_knowledge.json` - category keywords and generic purposes (committed, editable).
* `products.json` - OPTIONAL user-defined products: `[{"barcode": "...", "name": "...", "brand": "...", "category": "...", "purpose": "..."}]` (git-ignored).
* `settings.json` - optional overrides (git-ignored). `cache/lookups.json` - barcode lookup cache (git-ignored).
No images or audio are ever written here.
